# ✨ GradeGlow – Student Marks Calculator

A modern and animated Student Marks Calculator built using HTML, CSS, and JavaScript.

Calculate student marks, percentages, and grades with a beautiful, interactive interface.

## 🚀 Features

- Enter student name
- Enter marks for five subjects
- Automatically calculate total marks
- Calculate overall percentage
- Display student grade
- Animated percentage progress bar
- Smooth animations and transitions
- Modern glassmorphism UI design
- Responsive layout for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎨 Design Highlights

- Dark gradient background
- Glowing animated background effects
- Glass-style calculator card
- Interactive buttons
- Animated result section

## 📊 Grading System

| Percentage | Grade |
|---|---|
| 90% – 100% | A |
| 75% – 89% | B |
| 50% – 74% | C |
| Below 50% | F |

## 💻 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/abinash-patra01/StudentMarkCalculator.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enter student details and marks.
5. Click **Calculate Results**.
